# jira-cli — Docs

Living documentation bundle for `jira-cli`, the Jira Cloud read/browse CLI
(a fork of `active-collab-cli` with the API/domain layer swapped). Root of trace:
the [Constitution](/constitution.md). Every PRD, ADR, BDR, and issue resolves back
to it.

## Foundation

- [Constitution](/constitution.md) — product scope, data model, non-negotiables.
- [Architecture](/architecture.md) — living Mermaid module + data-flow views.

## Trail

- [PRDs](/prd/index.md) — what the system must do and why.
- [ADRs](/adr/index.md) — how the system is structured (decisions + rationale).
- [BDRs](/bdr/index.md) — observable behavior (Given/When/Then + test design).
- [Issues](/issues/index.md) — execution slices J0–J5.
- [Research](/research/index.md) — external evidence.

## Context

- [Context index](/context/index.md) — domain & module vocabulary.
- [Glossary](/context/glossary.md) — terms & acronyms.
