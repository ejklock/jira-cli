# J5 — i18n: English + Brazilian Portuguese CLI output

## Objective link

[PRD 0001](/prd/0001-jira-cloud-read-cli.md) R8 → reuses the AC `i18n` module and
the language-precedence behavior (env > DB setting > `en`).

## Context manifest

- **Touch:** `i18n` (en + pt-BR catalogs for the Jira-specific strings: setup
  messages, table headers, error/notice lines), `setup language [code]`, and the
  language bootstrap in `main`/`cli`.
- **Pattern:** the AC i18n catalog + `__()` wrapping + `_init_language` precedence
  is the reference; only the string set differs.
- **Note:** Jira data (status names, issue types) is **not** translated — only the
  tool's own chrome.

## Vertical Demo

- **Given** the env var unset,
  **When** I run `jira setup language pt-BR` then `jira mine`,
  **Then** the table headers, notices, and error lines render in pt-BR.
- **Given** `JIRA_CLI_LANG=en` set,
  **When** I run `jira mine`,
  **Then** output is English regardless of the stored setting (env precedence).
- **Unhappy path:** **When** I run `jira setup language zz`,
  **Then** it prints the unsupported-language error and exits 2.
